- **Asynchronous Loading**: `resource_preloader.gd` acts as an autoload singleton using `ResourceLoader.load_threaded_request` to preload scenes and warm up shaders without blocking the main thread, signaling completion via `all_loaded`.
- **Mission Orchestration**: `mission_flow_player.gd` (autoload) drives branching mission sequences defined in resources, handling checkpoints, timers, and command execution (e.g., spawn enemies, play sounds) by interfacing with a central `MissionManager`.
- **Layered Interaction Model**: Entities like `mina.gd`, `power_up.gd`, and `bot_simple.gd` use a `livello`/`current_height_level` property to manage vertical layering. Collision layers and visibility are dynamically calculated based on this level to simulate multi-floor interactions in a 2D space.
- **Global State Management**: `global_settings.gd` serves as the central hub for user preferences (graphics, audio, language), persisting to `user://settings.cfg` and applying changes runtime via signals like `settings_changed`.
